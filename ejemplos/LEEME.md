# Ejemplos para TextilFlow

El único ejemplo incluido es el caso base de **Confecciones Andina**.

Para cargarlo desde un archivo: Data Manager → **Cargar ejemplo desde archivo… → Elegir archivo…** y seleccione `01_confeccion_andina.xlsx`.
No borra nada: crea un taller nuevo con su escenario S0 (manual) ya simulado.

## Sus propios talleres
Descargue la plantilla (Data Manager → Crear plantilla), llénela con su caso y cárguela con el mismo botón o con «Importar».
Si le pide a una IA que la llene, indíquele que no cambie los encabezados, que cada ruta empiece en el Almacén y termine en
Despacho, y que las fracciones de las ramas de una misma prenda sumen 100 %.
Si el archivo tiene errores, el programa lo rechaza completo y dice en qué hoja y fila están.
